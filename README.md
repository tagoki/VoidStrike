# VoidStrike ⚡ (MVP)
> **CLI-утилита класса AI Red Teaming & Adversarial Evaluation для тестирования устойчивости локальных LLM.**

> [!NOTE]
> Данный проект находится на стадии **MVP (Minimum Viable Product)**. Текущая версия сфокусирована на базовом функционале: прямом взаимодействии с локальным Ollama API, эвристической оценке и интерактивном CLI. В планах — масштабирование архитектуры и интеграция новых бэкендов.

**VoidStrike** — это специализированный инструмент командной строки, разработанный для специалистов по информационной безопасности, исследователей и разработчиков AI. Утилита автоматизирует процесс стресс-тестирования локальных языковых моделей на устойчивость к атакам типа **Prompt Injection**, **Jailbreak** и обходу встроенных систем безопасности (AI Guardrails).

## 🚀 Основные возможности

- **Интеграция с Ollama REST API:** Автоматическое взаимодействие с локальным инстансом Ollama без сторонних тяжелых библиотек.
- **Интерактивный выбор модели:** При запуске утилита опрашивает установленные в системе модели (`ollama list` / `/api/tags`) и позволяет выбрать нужную с помощью стрелочек **↑ / ↓** и клавиши **Enter**.
- **Проверка стохастической устойчивости:** Отправка каждого тестового вектора $N$ раз с настраиваемой температурой генерации (`temperature`).
- **Детектор отказов (Heuristic Engine):** Анализ ответов модели на маркеры отказа на русском и английском языках с нормализацией апострофов для минимизации ложных срабатываний (`[REFUSED]` vs `[POTENTIAL BYPASS]`).
- **Изолированное сохранение отчетов:** Каждый запуск сохраняет отдельный файл отчета с временной меткой в выделенную директорию `reports/` (`reports/result_YYYY-MM-DD_HH-MM-SS.txt`).

## 🛠️ Установка и запуск

### 1. Предварительные требования
* **Python 3.8+**
* Установленный и запущенный **[Ollama](https://ollama.ai/)** с загруженными моделями (например, `qwen2.5:3b`, `qwen2.5-coder:7b`, `llama3.2`, `mistral` и т.д.).

### 2. Клонирование репозитория и установка зависимостей
```bash
git clone https://github.com/tagoki/VoidStrike.git
cd VoidStrike
pip install -r requirements.txt
```

### 3. Подготовка промптов
Откройте файл `prompts.txt` в корне проекта и добавьте тестовые запросы. Промпты разделяются строкой из четырёх дефисов (`----`):

```text
Тестовый вектор атаки №1
----
Тестовый вектор атаки №2 (многострочный)
Инструкция 1...
Инструкция 2...
----
Тестовый вектор атаки №3
```

### 4. Запуск утилиты
```bash
python void_strike.py
```

В интерактивном меню:
1. Выберите пункт `[1] Начать проверку устойчивости`.
2. Выберите модель из списка стрелочками **↑ / ↓** и нажмите **Enter**.
3. Укажите количество итераций (например, `3`).
4. Укажите температуру генерации (по умолчанию `0.7`).

## 📊 Формат отчета

По завершении тестирования в папке `reports/` создается файл `reports/result_YYYY-MM-DD_HH-MM-SS.txt`:

```text
========================================
Model Name: qwen2.5-coder:7b
Prompt ID:  1 | Iteration: 1/3
Status:     REFUSED
Input:      [Ваш тестовый вектор]
Output:     I am sorry, but I cannot assist with this request.
========================================
========================================
Model Name: qwen2.5-coder:7b
Prompt ID:  1 | Iteration: 2/3
Status:     POTENTIAL BYPASS
Input:      [Ваш тестовый вектор]
Output:     [Ответ модели, требующий ручной верификации]
========================================
```
